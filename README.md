# 📊 KRX ETF Radar (네이버 증권 ETF 실시간 종합 EDA 대시보드)

네이버 증권 국내 ETF API(`https://stock.naver.com/api/stockSecurity/etfs/v2/domestic`)를 통해 국내 상장 **1,170여 개 ETF 전종목**을 실시간으로 수집하고, 시장 구조, 유동성, 기간별 수익률, iNAV 괴리율 등을 다차원으로 진단하는 **정적 웹 종합 탐색적 데이터 분석(EDA) 대시보드**입니다.

GitHub Pages, Vercel, Netlify 등 정적 호스팅 환경에 즉시 배포할 수 있도록 순수 HTML/CSS/JavaScript 및 Chart.js로 구축되었으며, 오프라인 환경과 브라우저 직접 실행(`file:///`)도 완벽히 지원합니다.

---

## ✨ 핵심 기능 및 EDA 분석 구성

### 1. 📈 상단 시장 개요 KPI 스트립
- **총 상장 종목 수**: 1,171개 실시간 모니터링 (상승 / 하락 / 보합 종목 실시간 비율)
- **시장 순자산총액 (Total AUM)**: 457.6조 원 시장 전체 규모 합산
- **당일 총 거래대금 & 회전율**: 5.76조 원 거래대금 및 AUM 대비 일일 자산 회전율
- **평균 일일 등락률**: 시장 심리 지수 (Bull / Bear / Neutral 판정)
- **iNAV 평균 괴리율 & 이상치 집계**: 정상 추종 범위 vs 주의 종목 수 실시간 집계
- **1위 운용사 점유율**: 삼성자산운용(KODEX) 등 선두 운용사의 AUM 점유율

### 2. 🏛️ SECTION 01: 시장 구조 및 운용사 점유율 분석
- **운용사별 AUM 점유율 도넛 차트**: 삼성(KODEX), 미래에셋(TIGER), KB(RISE), 한국투자(ACE), 신한(SOL), 한화(PLUS) 등 상위 7대 운용사 및 기타 점유율 비교 (AUM 점유율 / 종목 수 점유율 원클릭 전환)
- **자산군 유형별 순자산 가로 바 차트**: 국내주식형, 해외주식형, 국내채권형, 해외채권형, 파생/레버리지, 혼합형 규모 분석

### 3. 💧 SECTION 02: 유동성 및 규모 (AUM vs 거래대금) 산점도
- **유동성 산점도 (Scatter Chart)**: X축 순자산(AUM) vs Y축 일일 거래대금 분포 (로그 스케일 / 선형 스케일 토글, 마우스 호버 시 종목별 세부 지표 툴팁)
- **Top 10 랭킹 차트**: 순자산총액 Top 10 / 당일 거래대금 Top 10 / 자산 회전율 Top 10 탭 전환 바 차트

### 4. 🎯 SECTION 03: 다각적 수익률 분포 및 성과 분석
- **기간별 수익률 히스토그램**: 1개월, 3개월, 6개월, 당일 등락률 선택에 따른 정규분포 및 구간별 빈도 분석
- **Top 7 & Bottom 7 성과 양극화 비교**: 선택 기간 동안 최고 수익률(Bull) 및 최저 수익률(Bear) 극단 종목 랭킹

### 5. ⚠️ SECTION 04: iNAV 괴리율 및 리스크 진단
- **iNAV 괴리율 구간 분포 도넛**: 정상(±1.0% 이내), 주의(±1.0%~2.0%), 위험(±2.0% 초과) 비중
- **당일 등락 심리 파이 차트**: 상승 vs 하락 vs 보합 비율
- **괴리율 이상치(Outlier) 경고 보드**: 러시아 ETF(ACE 러시아MSCI 등)처럼 실제 기초자산 거래정지나 LP 유동성 부족으로 시장가격과 순자산가치가 심각하게 벌어진 종목 실시간 경고 및 원인 해설

### 6. 🔍 SECTION 05: 전종목 인터랙티브 탐색기 & 데이터 테이블
- **실시간 통합 검색**: 종목명 및 6자리 종목코드 즉시 필터링
- **다차원 필터 바**: 운용사 선택, 자산유형 선택, 가격 변동 칩(상승/하락/보합), 괴리율 상태 칩, 규모 칩(1조원 이상 등)
- **전 컬럼 정렬**: AUM순, 거래대금순, 등락률순, 1M/3M/6M 수익률순, 괴리율순 오름차순/내림차순 정렬
- **페이지네이션**: 15 / 30 / 50 / 100개 단위 보기 및 직관적인 페이지 이동
- **종목 상세 진단 모달**: 종목 클릭 시 현재가, iNAV, 괴리율 평가, AUM 시장 순위, 회전율, 네이버 증권 링크 제공
- **CSV 데이터 내보내기**: 엑셀 한글 깨짐을 방지하는 UTF-8 BOM 지원 CSV 원클릭 다운로드

### 7. 🎨 테마 및 사용자 편의성
- **다크 모드 / 라이트 모드**: 사용자의 눈 피로도를 낮추는 핀테크 스타일 테마 (로컬 스토리지 자동 저장)
- **등락 색상 모드 토글**: 한국 증시 기준(상승 빨강 / 하락 파랑) ⇄ 글로벌 기준(상승 초록 / 하락 빨강)

## 🚀 빠른 시작 및 로컬 실행

### 1. 브라우저에서 바로 열기
별도의 웹 서버 없이도 `index.html` 파일을 더블 클릭하여 브라우저에서 즉시 실행할 수 있습니다. (`data/etf_data.js` 내장 스냅샷을 통해 CORS 없이 즉시 구동)

### 2. 로컬 웹 서버 실행 (권장)
Python이 설치되어 있다면 다음 명령어로 간편하게 로컬 서버를 구동할 수 있습니다:

```bash
# Python 내장 http 서버 실행
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속

## 🐍 최신 ETF 데이터 수집 (Python & uv)

프로젝트에는 네이버 증권 API로부터 1,170여 개 전종목을 1초 만에 병렬/페이징 수집하여 가공하는 `fetch_etf.py`가 포함되어 있습니다.

```bash
# uv를 통해 바로 실행 (가상환경 자동 관리)
uv run fetch_etf.py
```

실행 시 `data/etf_data.json` 및 `data/etf_data.js`가 자동으로 최신 데이터로 업데이트됩니다.

## 🌐 GitHub Pages 정적 배포 안내

이 저장소를 GitHub에 Push한 뒤 아래 설정만 활성화하면 무료로 정적 웹페이지를 배포할 수 있습니다:

1. GitHub 저장소의 **Settings > Pages** 메뉴로 이동합니다.
2. **Build and deployment > Source**를 **GitHub Actions**로 설정합니다.
3. 저장소에 포함된 `.github/workflows/update_data.yml` 워크플로우에 의해:
   - 매 평일 장마감 후(16:30 KST) 자동으로 최신 ETF 데이터를 크롤링하여 커밋합니다.
   - 항상 최신 데이터가 반영된 정적 대시보드가 자동으로 재배포됩니다.

## 📁 파일 구조

```
etfdashboard/
├── index.html                 # 대시보드 메인 HTML 페이지
├── style.css                  # 모던 미니멀 UI 디자인 시스템 및 다크모드 스타일
├── app.js                     # Chart.js 시각화, API 수집, 필터/정렬/모달 로직
├── fetch_etf.py               # uv 기반 네이버 ETF 전종목 수집 및 정제 파이썬 스크립트
├── data/
│   ├── etf_data.json          # 최신 ETF 전체 데이터셋 (JSON 포맷)
│   └── etf_data.js            # file:// 오프라인 로딩용 스냅샷 자바스크립트
└── .github/
    └── workflows/
        └── update_data.yml    # 평일 장마감 후 자동 갱신 및 GitHub Pages 배포 워크플로우
```
